# ADR-004 — 段落按行切分填满页面与续段顶格

- 状态：已接受
- 日期：2026-08-26
- 触发：分页模式两个排版缺陷——①长段落跨页后续段带首行缩进（视觉上像新段落）；②普通段落放不下本页剩余空间时整体挪到下一页，当前页只剩几个短段落，再被底部对齐把剩余高度摊到仅剩几行上，行距被拉得极大。

## 背景

旧 `ChapterPaginator` 只对「超过整页高的超长段」按行切分；普通段落一律原子放置，放不下剩余空间就整段移下一页。这继承了「双语原子性」的旧边界（双语对默认不可拆），但把代价扩大到了 zh 模式的所有段落：

- 页面稀疏：短段落 + 一个中等长度长段落混排时，长段挪页导致当前页大量留白；
- 行距拉伸：`bottomJustify` 把剩余高度均摊到仅剩的几行，行距明显大于正常设置；
- 续段缩进：切段续排的片段仍用带 `TextIndent(firstLine)` 的正文样式测量和渲染，第二页首字缩进，违反「同一段落的延续行顶格」的排版惯例。

## 决策

### D1 按行切分填满当前页

段落放不下本页剩余空间时，只要剩余空间还能容纳该段的**至少一行**，就从行边界切开：本页排前半、剩余文本续排下一页（对齐 Legado 跨页续排）。只有剩余空间连一行都放不下时才翻页后再处理。由此废除旧的「普通段落原子、整段挪页」策略，「双语原子性」边界同步废止：en 模式双语对同样按英文行切分填页。

### D2 续段顶格

同段跨页的延续片段不带首行缩进（测量与渲染同一口径）：`PageUnit.Para` 新增 `continuation` 标记，排版器用无 `textIndent` 的派生样式测量续段，`PageRenderer`/`BilingualParagraph`/仿真位图重测按同一标记去缩进。首片段保留段落首行缩进。

### D3 不变的部分

- 所有片段仍绑定同一个原文范围（`sourceStartOffset/sourceEndOffset` 恒指整个段落），offset→页映射语义不变；
- 双语对每个带译文的片段段尾都显示中文气泡，点任一气泡弹出整段中文侧文本（2026-08-26 修订：初版决策为仅首片段带气泡、续段无气泡，实际使用中发现续页看译文需回翻上一页，体验割裂，且 `pairHead` 链路因此失去存在意义，遂放开到所有片段并删除该链路）；
- 切段拼接不丢字符（行尾空白裁剪规则沿用 `splitLayout`）；
- `bottomJustify` 开关与末页豁免保持不变——填满策略落地后非末页几乎无剩余高度可摊，行距拉伸问题随根因消失；
- 标题、插图块的排版规则不变（插图仍整图适配不拆）。

## 后果

- 非末页在正常字号下剩余高度不足一行，页面密度均匀，底部对齐基本不再触发拉伸；
- 跨页处出现段中断行（书籍排版常态），续段顶格使其可与新段落明确区分；
- en 模式下同屏可能出现同一双语对的多个气泡（每片段一个），弹窗内容恒为整段译文，信息不因切段而残缺；
- 「每段一个首片段」成为新的结构不变量，单测断言 pairHead 唯一性、切段拼接无损与非末页低 slack。
