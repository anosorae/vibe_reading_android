# ADR-003 — 英文原版书阅读模式与书籍原文语言

- 状态：已接受
- 日期：2026-08-26
- 触发：支持英文原版书阅读：默认显示英文原文，段尾气泡点击弹中文译文；中文模式显示整章中文译文。中文书阅读模式保持不变。

## 背景

VibeReading 自始面向中文 TXT/EPUB：章节原文是中文，`translatedContent` 恒为英文译文，翻译管线（`LlmApiService.SYSTEM_PROMPT`/`buildUserPrompt`）硬编码「整章中文→英文」，渲染层按 `mode == "zh" / "en"` 分支，其中：

- `zh` 模式：中文原文正文，无气泡；
- `en` 模式：英文译文正文 + 段尾「原文气泡」（弹窗显示中文原文）。

`books.languageMode`（v9 加入）同时充当「按书绑定的阅读模式」，导入时全部默认 `zh`。

英文原版书把上述方向对称翻转：原文=英文、译文=中文、默认显示原文。核心权衡：是否在交互骨架不变的前提下抽出「书籍原文语言」这一独立概念，让渲染与翻译按方向取插槽。

## 决策

### D1 书籍原文语言独立于显示模式

新增 `Book.sourceLanguage`（`"zh"`/`"en"`），是书的**不变属性**（与 `format` 同级）；现有 `languageMode` 语义钉死为「显示模式」（zh=中文侧正文 / en=英文侧正文），默认=原文语言，导入时令 `languageMode = sourceLanguage`（英文书首开即原文模式），切换后按书持久化。

二者必须分列：英文书被切到中文显示后 `languageMode` 变为 `zh`，但原文语言仍是英文，翻译方向与插槽取决于后者。改动 `sourceLanguage` 是破坏性操作：本书全部章节译文按旧方向生成，修正时必须清空并重置 PENDING，同时把显示模式重置为新原文语言（否则出现「中文模式、英文字」的自相矛盾界面）。

### D2 对称显示模型（插槽互换）

| 原文语言 | 英文显示模式（默认） | 中文模式 |
|---|---|---|
| 中文（现状不变） | 英文**译文**正文 + 气泡→中文**原文** | 中文原文正文，无气泡 |
| 英文（新增） | 英文**原文**正文 + 气泡→中文**译文** | 整章中文**译文**正文，无气泡 |

统一规则：气泡只在英文显示模式出现；弹窗恒为**中文侧**文本；渲染层按「原文语言 + 模式」把每段的原文侧/译文侧填入英文位/中文位。术语随之改名：「原文气泡」→「中文气泡」（对英文书弹窗里装的是译文，不再误导）；「双语段落」重定义为同段原文与译文的跨语言配对。

### D3 导入期自动判定 + 书架可修正

TXT/EPUB 导入时按章节顺序取首个「抽样量 ≥60 字符」的章节（跳过「卷首」等空章节/纯封面页，避免空样本保守误判），抽其前 20 段样本文本，CJK 字符占比 ≥30% 判 `zh`、否则 `en`（日韩等非中英书不在支持范围，按 CJK 占比天然归入中文分支、接受方向误判）。书架长按菜单（现有 ModalBottomSheet）新增「本书原文语言」修正项，选中即弹确认框（警示清空译文），确认后按 D1 处理。

### D4 翻译管线按方向参数化

`TranslationService.translateStream` 增加 `sourceLanguage` 参数（按书传递，不放进全局 `LlmSettings`/档案——那是跨书配置，原文语言是书属性）；`SYSTEM_PROMPT`/`buildUserPrompt` 按方向生成「中文→英文」或「英文→中文」，`[N]` 标记契约与 `parseBilingualParagraphs` 零改动。~~上下文增强 `loadContext` 继续取上一章**译文**（目标语言版本）~~（该功能已随设置项移除，翻译为单章、不带任何上文，与方向决策无关），仅 prompt 措辞按方向泛化。

翻译门控：英文书两种显示模式都预译当前+下一章（英文模式的气泡与中文模式正文共用同一份中文译文）；中文书保持仅 `en` 模式翻译。英文书 `en` 模式下译文到达不触发布局重排（正文=原文恒定），译文未就绪时点击气泡弹窗显示「译文生成中…」占位；未译回退与现状对称：中文书 `en` 模式→中文原文、英文书 `zh` 模式→英文原文，均自动翻译自愈。

**考虑过的替代方案**（拒绝理由）：
- *按段落惰性翻译*（点气泡才译该段）——引入平行于整章 `[N]` 管线的第二套翻译子系统与存储，架构代价大、收益低；
- *禁止切入中文模式直到译完*——硬门槛体验差；
- *日韩/混杂书设「仅原文」第三态*——状态机与 UI 概念负担，实际无此输入；
- *`sourceLanguage` 塞进 `LlmSettings`/档案*——原文语言是书属性，放全局配置会跨书串味。

## 影响

- Room schema v12→v13：`books` 加 `sourceLanguage TEXT NOT NULL DEFAULT 'zh'`，`MIGRATION_12_13` 注册进迁移链，schema 导出 `app/schemas`；存量书全部视为中文书，行为不变。
- 改动点：`BookEntity`/`Book`/`BookDao`（新列 + 按书清空译文 DAO）、`BookshelfViewModel`（检测 + 修正）、`BookshelfScreen`（长按菜单 + 确认框）、`TranslationService`/`LlmApiService`/`TranslationCoordinator`/`ReaderViewModel`（方向参数 + 门控）、`ReadingContent`/`ReadingContentRenderer`/`TextPaginator`/`BookPager`（双路径插槽）、`BilingualParagraph`/`ReaderPalette`（中文气泡改名 + 占位文案）、`EpubParser`（空结构章剔除 + 卷首/书末标题随原文语言本地化）。
- 测试：方向 prompt、英文书 en/zh 分页插槽、检测判定（含空首章跳过）、DAO 清空、翻译状态机英文书全流程。
- AGENTS.md 目录结构与 gotchas 在实现落地时同步更新。
